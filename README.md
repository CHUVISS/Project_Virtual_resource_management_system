Консольное приложение для учёта виртуальных ресурсов (виртуальных машин), пользователей и заявок на выделение ресурсов. С ПР3 предметная область реализована в виде объектной модели на классах Python.

## 🎯 Назначение
Приложение ведёт учёт виртуальных ресурсов — CPU, RAM, дискового пространства — и заявок пользователей на их выделение, позволяя оценить доступность и стоимость аренды ресурса.

## 👥 Целевая аудитория
Системные администраторы и DevOps-инженеры, а также владельцы проектов, которым нужно отслеживать выделенные вычислительные ресурсы, пользователей и стоимость аренды.

## 📦 Предметная область
Объекты предметной области могут иметь несколько активных заявок только на разные даты: одно и то же сочетание «ресурс + дата» не может быть занято дважды, пока заявка не отменена. Отменённая заявка не блокирует ресурс.

## 🧩 Основные сущности

### `Resource` — виртуальный ресурс
Атрибуты: `id`, `name`, `cpu_cores`, `ram_gb`, `storage_gb`
Методы:
- `is_suitable_for()` — проверка достаточности RAM;
- `calculate_monthly_cost()` — расчёт ежемесячной стоимости аренды;
- `validate_ram()` — статический метод проверки корректности значения RAM;
- `__str__()` — строковое представление ресурса.

### `User` — пользователь
Атрибуты: `id`, `name`, `email`
Методы:
- `from_data()` — создание пользователя из словаря (classmethod);
- `__str__()` — строковое представление пользователя.

### `Allocation` — заявка на выделение ресурса
Атрибуты: `id`, `resource` (объект `Resource`), `allocation_date`, `user` (объект `User`), `is_cancelled`
Методы:
- `cancel()` — отмена заявки (без удаления из коллекции);
- `__str__()` — строковое представление заявки с учётом её статуса.

`Allocation` хранит ссылки на объекты `Resource` и `User`, а не только их идентификаторы — так данные связанных объектов доступны напрямую: `allocation.resource.name`, `allocation.user.email`.

## ⚙️ Возможности
- просмотр и поиск ресурсов по названию;
- проверка вместимости ресурса по объёму RAM;
- добавление и просмотр пользователей;
- проверка доступности ресурса на дату;
- создание и отмена заявок на выделение ресурса;
- расчёт ежемесячной стоимости аренды;
- статистика по имеющимся ресурсам.

```
virtual-resources-manager/
├── README.md
├── requirements.txt
├── conftest.py
├── main.py                — точка запуска, меню приложения
├── models/
│   ├── __init__.py         — экспорт классов пакета
│   ├── resource.py         — класс Resource и функции работы с ресурсами

├── utils.py                  — безопасный ввод чисел и дат
├── data/

│   ├── users.json
│   └── allocations.json

    ├── test_resources.py
    ├── test_users.py
    └── test_allocations.py
```

## 💾 Хранение данных
Данные хранятся в JSON-файлах каталога `data/`. При загрузке `storage.py` преобразует словари JSON в объекты `Resource`, `User` и `Allocation`; при сохранении — объекты обратно в словари. В `allocations.json` заявка ссылается на ресурс и пользователя через `resource_id` и `user_id`, а не через сами объекты.

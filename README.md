# 🖥️ Система управления виртуальными ресурсами

**Преподаватель:** Ящун Татьяна Викторовна

Консольное приложение для учёта виртуальных ресурсов (виртуальных машин) и управления заявками на их выделение. Разрабатывается поэтапно на протяжении курса — от базовых скриптов на Python (ПР1) до полноценного веб-приложения на Django.

## 🎯 Назначение
Приложение ведёт учёт виртуальных ресурсов — CPU, RAM, дискового пространства — и заявок на их выделение, позволяя быстро оценить доступность и стоимость аренды ресурса.

## 👥 Целевая аудитория
Системные администраторы и DevOps-инженеры, а также владельцы проектов, которым нужно отслеживать выделенные вычислительные ресурсы и их стоимость.

## 📦 Предметная область
Управление виртуальными вычислительными ресурсами: выделение ресурсов, учёт их занятости и расчёт стоимости аренды виртуальных машин.

## 🧩 Основные сущности
- Виртуальный ресурс (виртуальная машина) — CPU, RAM, хранилище
- Заявка на выделение ресурса — ресурс и дата

## ⚙️ Возможности
- просмотр и поиск ресурсов по названию;
- проверка вместимости ресурса по объёму RAM;
- проверка доступности ресурса на дату;
- создание и отмена заявок на выделение ресурса;
- расчёт ежемесячной стоимости аренды;
- статистика по имеющимся ресурсам (количество, средний объём RAM, суммарная стоимость).

## 🗂️ Структура проекта
```
virtual-resources-manager/
├── README.md
├── requirements.txt
├── main.py           — точка запуска, меню приложения
├── resources.py       — работа с виртуальными ресурсами
├── allocations.py     — работа с заявками на выделение
├── storage.py          — сохранение и загрузка данных (JSON)
├── utils.py             — безопасный ввод чисел и дат
├── data/
│   ├── resources.json
│   └── allocations.json
└── tests/
    ├── test_resources.py
    └── test_allocations.py
```

## 💾 Формат хранения данных
Ресурсы и заявки хранятся в JSON-файлах каталога `data/`. Ресурс описывается идентификатором, названием, числом ядер CPU, объёмом RAM и хранилища. Заявка — идентификатором, ресурсом и датой выделения.

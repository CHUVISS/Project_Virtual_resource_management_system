# Система управления виртуальными ресурсами

## Назначение
Приложение предназначено для учёта и управления виртуальными ресурсами (виртуальными машинами, объёмом CPU, RAM и дискового пространства), которые выделяются пользователям или проектам в рамках облачной инфраструктуры.

## Целевая аудитория
Системные администраторы и DevOps-инженеры, а также владельцы проектов, которым необходимо отслеживать выделенные вычислительные ресурсы и их стоимость.

## Предметная область
Управление виртуальными вычислительными ресурсами: выделение ресурсов, учёт их занятости и расчёт стоимости аренды виртуальных машин и связанных с ними компонентов (CPU, RAM, хранилище).

## Основные сущности
- Виртуальный ресурс (виртуальная машина)
- Пользователь / проект, использующий ресурс
- Заявка на выделение или расширение ресурса

## Основные функции
- Проверка доступности ресурса для выделения
- Расчёт ежемесячной стоимости аренды ресурса
- Проверка достаточности ресурсов при запросе на расширение

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django для управления ресурсами;
- подключение базы данных для хранения ресурсов и заявок;
- реализация пользователей и разграничения доступа;
- разработка REST API для управления ресурсами;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD.
